# Portfolio build plan

1. Research: read 15+ Codrops articles reached from the listings, open available live references, document five usable patterns. Complete before application code.
2. Establish facts: inspect the latest Antigravity resume task, resume source and newest compiled PDF; rank GitHub projects using live metadata and README evidence.
3. Choose a direction: compare three concepts; document positioning, factual copy, source provenance and unresolved claims.
4. Build incrementally: Next.js App Router, TypeScript, Tailwind; server-rendered text and isolated client interactions. First hero/navigation, then selected work and individual case studies, then biography, experience/education, skills, publication and contact.
5. Review mobile and desktop after each major group. Implement two themes, reduced motion, keyboard controls, responsive SVG and progressive enhancement.
6. Finish: metadata, OG image, favicon, sitemap, downloadable resume, README, production build, accessibility/interaction checks and Lighthouse audits. Fix observed problems and record actual scores.

## Constraints

- All personal claims need resume/GitHub evidence; no invented clients or outcomes.
- Original SVG diagrams and typography; no copied reference assets or source.
- No heavy WebGL or mandatory animation; content is immediately readable.
- Deployable on Vercel without secrets or services. A final deployment domain is configuration, not a fabricated personal URL.
