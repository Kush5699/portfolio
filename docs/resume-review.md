## Synthesis used on the website

- Position as **ML researcher & AI systems builder**, rather than reproducing any application's job title.
- Keep the common recent education and experience dates: M.Tech 2025–present, class of 2027; B.E 2021–2025; IRLP Lab Sep 2025–present; HP Param Jun 2024–Jul 2025. Older resumes use different HP dates/titles; latest consistent versions supply this timeline.
- Use the Lexsi research and systems balance, MatlabInfotech contact context, CRED's recent SLA project, DevX's tabular ML emphasis, and repository-specific architectures for the six selected case studies.
- No résumé companies are implied to be employers. Only DAU/IRLP and HP Param are employment entries; teaching/ambassador activities are separate.
- Do not present 110K as a verified number of SKU records: SKU-110K is a named dataset, whose README describes 11,762 images and 1.73M annotations. Show the reproducible reported 58.3 mAP@50–95 benchmark with a source link instead.
- Use cautious factual role descriptions rather than importing every tailored latency/coverage/speed claim.
- For CodeResidency, use Flutter + FastAPI + Google ADK from GitHub; do not import contradictory Next.js/Node.js variants.
